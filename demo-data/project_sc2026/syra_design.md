# 设计文档摘要（SYRA）· 审查对象

> 虚构示例。展示进入 AI 设计审查前的设计文档形态（真实系统为需求管理工具中的 SYRA/SYAD）。

## 1. 检测电路
光电二极管接收 + 前置放大 + 比较器，输出数字电平；检测距离 0.3~0.5 m（透过型），灵敏度调节电位器增益可调。
标签：光学 / 模拟电路

## 2. 环境光抑制
载波调制（10 kHz）+ 带通滤波，抑制直流/低频环境光对感测距离的干扰。
标签：抗扰 / 信号处理

## 3. 输出接口
NPN / PNP 可选，推挽输出 + 短路保护，响应时间 ≤ 1 ms。
标签：输出 / 保护

## 4. 供电
DC 10~30 V，反接保护。
标签：电源
